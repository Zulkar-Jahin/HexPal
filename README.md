# HexPal

Turn a single color into a complete palette.

HexPal takes one HEX or RGB value and generates tints, shades, tones, a 50–900
numbered scale, and standard color harmonies — all copy-ready for your next
project. No build step, no dependencies, one HTML file.

**Live:** [hexpal.vercel.app](https://hexpal.vercel.app/)

## Features

- **Flexible input** — accepts `#c17440`, `c17440`, `#c74`, `rgb(193,116,64)` or `193, 116, 64`
- **Color details** — HEX, RGB and HSL values, plus contrast ratios against white and black
- **Tints, shades and tones** — stepped mixes with white, black and gray
- **50 → 900 scale** — a design-system style ramp built from the base hue
- **Harmonies** — complementary, analogous, triadic, split-complementary and tetradic
- **One-click copy** — click any swatch to copy its HEX, or export the full scale as CSS custom properties
- **Color picker & random** — grab a color visually or generate one to explore

## Usage

Open the live site, or run it locally:

```bash
git clone https://github.com/Zulkar-Jahin/HexPal.git
cd HexPal
```

Then open `index.html` in any browser. There is nothing to install.

## Built with

Vanilla HTML, CSS and JavaScript. No frameworks, no package manager, no dependencies.
